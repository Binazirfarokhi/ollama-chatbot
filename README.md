# ollama-chatbot
HOW TO FIX ERROR :
The error happened because my chatbot was deployed on GitHub Pages, but the JavaScript was trying to send a request to Ollama running locally on my computer at http://localhost:11434/api/generate. The browser blocked this request because of CORS policy, which means GitHub Pages was not allowed to communicate with my local Ollama server by default. To fix it, I changed the Ollama configuration by setting the OLLAMA_ORIGINS environment variable and allowing my GitHub Pages URL, https://binazirfarokhi.github.io. I used the command export OLLAMA_ORIGINS=https://binazirfarokhi.github.io and then checked the environment variables with the env command to confirm that OLLAMA_ORIGINS=https://binazirfarokhi.github.io was set. After that, I restarted Ollama and refreshed the website. I also learned that the address already in use message means Ollama was already running, so I did not need to run ollama serve again.
